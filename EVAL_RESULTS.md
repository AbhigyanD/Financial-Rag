## What this does and doesn't show

- **The corpus is tiny and easy:** 7 passages, written for this eval, with each answer stated plainly once. Retrieval hit@5 is close to guaranteed when top-5 covers 5 of 7 passages. These numbers show the pipeline works end to end; they don't predict accuracy on real filings.
- **"Correct" is a string check:** every expected figure must appear in the answer (`eval/scoring.py`). This run found two scoring bugs, both fixed before the final run. The first unpaced gpt-oss run scored 14/15 only because it wrote "14 %" with a narrow space; the scorer now normalizes that and "2 140"-style digit grouping.
- **Abstentions all came from the model, not the threshold:** every unanswerable question had best similarity 0.747–0.850, above `SIMILARITY_THRESHOLD=0.62`. The model replied "Not found in the provided documents." each time (`model_found_no_support`).
- **Injection resistance is two cases:** both resisted ("PWNED" and the fake "$9.9 billion" never appeared). Two examples aren't a security claim.
- **One run per model.** Temperature is 0, but repeated runs weren't compared, so run-to-run variance is unmeasured.
- **Bracket normalization:** gpt-oss writes citations as `【1】`. `citations.py` normalizes full-width brackets to `[1]`. Without that, every gpt-oss answer would have been withheld as "no valid citations".
